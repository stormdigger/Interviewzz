## 🎯 How the Books Are Structured

Every book follows the same skeleton so you always know where you are:

```
┌─────────────────────────────────────────────┐
│  1. Mental Model      → the diagram first   │
│  2. Fundamentals      → the "why"           │
│  3. Deep Mechanics    → the "how"           │
│  4. Practical Patterns→ the "when"          │
│  5. Production Reality→ what breaks         │
│  6. Interview Section → Q&A + drills        │
│  7. Cheat Sheet       → 1-page recall       │
└─────────────────────────────────────────────┘
```

**Legend used throughout:**

| Symbol | Meaning |
|---|---|
| 🧠 | Mental model / intuition |
| ⚙️ | Internal mechanics |
| ⚠️ | Common pitfall / gotcha |
| 🏭 | Production consideration |
| 🎤 | Interview question |
| 📊 | Diagram or table |
| 🔬 | Deep dive (optional first pass) |
